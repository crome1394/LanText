# Contributing to LanText

Thanks for taking this apart. The point of the project is a **LAN-only** SMS
companion that **does not** become the default messenger. Please keep that
invariant unless a change is explicitly about opting into default-app status.

## Development setup

- JDK **17**
- Android SDK with `compileSdk` 36 (`ANDROID_HOME` set)
- No Google Play services required

```bash
export JAVA_HOME="$HOME/opt/jdk-17"
export ANDROID_HOME="$HOME/Android/Sdk"
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
./gradlew :app:installDebug
```

`local.properties` is generated by your machine and is gitignored. Do not
commit it, keystores, or APKs.

The debug application id is `app.lantext.debug` so it can sit next to a
release install.

## Layout

| Path | What |
|---|---|
| `app/src/main/java/app/lantext/` | App: settings, Wi-Fi gate, HTTPS server, SMS/MMS |
| `app/src/main/java/com/google/android/mms/pdu_alt/` | Vendored AOSP/klinker PDU composer (Apache 2.0) |
| `app/src/main/assets/web/` | The computer UI (`index.html`, `app.js`, `styles.css`) |
| `app/src/main/java/app/lantext/widget/` | Home-screen on/off widget |
| `fastlane/metadata/android/en-US/` | F-Droid listing |

Kotlin style is the official one (`kotlin.code.style=official`). Web UI is
plain HTML/CSS/JS — no bundler.

## What to test by hand

There is no substitute for a phone on Wi-Fi and a browser on the same LAN:

1. Allowlist SSID, turn web access on, open the URL, pair with PIN + Approve.
2. Send an SMS to yourself; it should appear in the default messenger and in
   the web UI without a reload (WebSocket).
3. Paste a picture into the composer and confirm the carrier actually sends
   it (not only a failed outgoing item in Fossify / Google Messages).
4. Leave the allowed Wi-Fi; the server should stop.
5. Toggle the widget.

## Releases

1. Bump `versionName` and `versionCode` in `app/build.gradle.kts`.
2. Add a section to [CHANGELOG.md](CHANGELOG.md).
3. Add `fastlane/metadata/android/en-US/changelogs/<versionCode>.txt`
   (max 500 characters).
4. Commit, tag `v<versionName>` (example: `v0.1.0`), and push the tag.

Do not put signing keys in the repo. F-Droid builds from the tag.
