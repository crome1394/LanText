Permissions LanText needs

Android will show a system prompt for each of these. Nothing they unlock is uploaded. Nearby devices and location are only so the inbox can read the Wi-Fi name.

SMS

Needed

Read the system inbox and send texts through your carrier. Your default messenger stays in charge.

Contacts

Needed

Show names, and save or add a second number from the computer. Contacts stay on this phone.

Notifications

Needed

Pairing prompts, and the silent notice Android requires while the LAN server is running.

Nearby devices

Needed

Android’s name for reading the Wi-Fi you are on — not a scan for headphones or other phones.

Location

Needed

On older Android, the Wi-Fi name is gated behind location. Not GPS, not maps. Coordinates are never stored or sent.

Grant all

If Android does not ask again, enable them in Settings → Apps → LanText → Permissions.
